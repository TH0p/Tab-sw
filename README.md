# Tab To Next Tab

A minimal Sine JavaScript mod for Zen Browser.

## Behavior

- `Tab` → switches to the next open tab.
- At the last tab, `Tab` wraps to the first tab.
- `Shift + Tab` is untouched.
- `Ctrl/Alt/Meta + Tab` is untouched.
- No CSS or visual changes.

## Target

Zen Browser 1.22.3b / Firefox 156.0.1.

## Installation

Install this repository/package through Sine as an unpublished JavaScript mod.

Because this is a privileged browser-chrome JavaScript mod, Sine may require:
**Enable installing JS from unofficial sources (unsafe)**.

After installing, restart Zen.

## Uninstall

Disable/remove the mod from Sine and restart Zen.
