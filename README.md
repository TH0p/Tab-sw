# Tab To Next Tab

Zen Browser / Sine JavaScript mod.

## Behavior
- Tab -> next open tab
- Shift+Tab -> unchanged
- Ctrl/Alt/Meta + Tab -> unchanged
- No visual changes

## Installation
Install the folder/repository through Sine as an unpublished JavaScript mod.
If Sine asks for permission to run unsafe/untrusted JavaScript, allow it for this mod.

Restart Zen after installation if the mod does not activate immediately.

## Important
This mod intentionally makes Tab switch tabs even when a webpage normally uses Tab for focus navigation.
